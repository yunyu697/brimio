# 设计稿 vs 当前实现 对照表

配套 `Design/SPEC.md`、`Design/preview.html`。本表只列差异与判定，不改任何源码或既有文档。

## 0. 口径

| 项 | 说明 |
| --- | --- |
| 规范期望值 | 取自 `preview.html` 的标注与 `SPEC.md` 的公式 |
| 当前实测值 | 优先取实施方同版源码的**离屏渲染实测**（2026-11-16，逐像素，所有页可测）；其余取 `outputs/baseline/*/metrics.json`（2x 截图逐像素分析，03:58） |
| 单位 | pt；容差 ±0.5pt |
| 横向基准 | **内容盒左缘**（容器/填充块/虚线框的左缘），不是字形或图标的墨迹 |
| 判定 | 「实现偏离」= 现有代码没守已经成立的统一口径；「规范要求改」= 规范把目标值定死，需要改实现/文档；「待核」= 现有测量口径不自洽 |

> **口径已更新（v1.1）**：离屏实测显示**所有页内容盒左缘都是 23.0**（含设置页），到可见侧壁的净间隙 6.0（文件架缩略图行 8.0）。旧稿据截图估的「设置页 7pt」不再成立，相关判据已撤回（见 §1.1）。设置页看起来更贴边，是因为它是唯一有整行填充底色的页：填充的边界落在 23，而文字页的视觉边界落在字形墨迹上（少约 1pt 字面留白）。
>
> 另一处口径差异：`baseline` 记录的「净间隙 7.0pt」是图标墨迹到侧壁的距离，不是内容盒到侧壁的距离，两者不可混用。

### 2.1 首页高度（规范要求改，不是 bug）

同一个「声明 56 槽位、实际内容更少、居中摊白」的根因，在首页有三个现场。规范侧给出的目标版式见 SPEC §8.2 B/C/D。

| # | 态 | 规范期望 H | 规范内容 C | 版式（行高 / 位置） | 当前实测 | 差异 | 判定 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| H1 | 空 | **107** | 15 | 单行 11/15，x 23，y 76（基线 87.4） | 148，底部余量 39.0 | −41 | **规范要求改** |
| H2 | 权限被拒 | **120** | 28 | 单行 28（手形 16 + 文字 + 右箭头 16），x 23…277 | 148，底部余量 37.0 | −28 | **规范要求改** |

## 4. 判定汇总

- **实现偏离（按 bug 修）**：S3（112 固定槽位）、S4（54pt 真空）、O1c/O1d/O1e（首页三态共用一个 56 槽位、居中摊白）。
- **规范要求改（按新目标改）**：S5（高度 166/194/222）、S6（摘要层级）、S7（新增已开启列表）、S8（`FillInset`：按钮 246 @ 27）、H1–H3（首页 107 / 120 / 120）、M1–M3（双行档 122 / 单行容量 / 档位由文案表声明）。
- **撤回**：S1、S2（「7pt 内缩」不成立，实测 23.0）。
- **待核**：O6（文件架露出 20 vs 40）。
- **文档**：D1（216/140 → 202/126）、D3（补测量基准）。
- **不动**：播放中 148、计时器、闭合态、文件架 0–3 条、按钮的样式（只动宽度与位置）。

> 根因链只剩两条，其它都是它们的派生：
> ① **内容高度按槽位声明**（设置页 112、首页 56）→ 真空（54 / 39 / 37）；
> ② **填充面与文字用同一条边界** → 设置页读起来贴边（新增 `FillInset` 4，不是改内容盒）。
> 内容盒 23 自始至终成立，不需要改。

## 5. 复核方法（实施方照此填实测）

1. 2x 截图，按形状左上角建坐标；先找形状左缘（不是窗口左缘，窗口有 8pt 边距）。
2. 量内容盒左缘：取行容器/虚线框/按钮底的左缘，期望 23；不要取字形墨迹。
3. 量内容顶：chrome 首个图标顶 42（= 36 + 6），内容区顶 76。
4. 量底部：最后一行的 **frame** 下沿 + 16 = 面板高；不要量字形。
5. 设置页分别截 0 / 1 / ≥2 个已开启，验 166 / 194 / 222。
6. 首页分别截 播放中 / 只有播放状态 / 权限被拒 / 空，验 148 / 120 / 120 / 107。
7. 设置页量两条竖线：摘要行左缘 23、按钮填充缘 27；两者差 4，且右缘 277 / 273 对称。
8. 文件架截 0 / 2 / 4 条，验 124 / 164 / 232，量第 4 行露出高度。
9. 把实测值填回本表「当前实测」列，差异 > 0.5pt 即开缺陷。
